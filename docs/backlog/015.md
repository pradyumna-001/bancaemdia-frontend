## Acceptance

Mount/unmount/reload não criam múltiplos loops nem reenvio; todos os estados reais são testados. O acompanhamento começa após o upload aceito, sem etapa ou aviso de custo de processamento; limites e falhas retornados pela API têm recuperação adequada. Esta issue não depende de aprovação de gasto pelo usuário.
